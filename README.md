# Flyr - A4 6面フライヤー印刷用PDF作成ツール 📄✂️

A4用紙1枚に対して、フライヤー画像を無駄なく**6枚面付け（上段4枚＋下段2枚）**して配置し、カット用の高解像度PDF（300 DPI）をブラウザ完結で作成・印刷できるWebアプリケーションです。

---

## 🌟 主な特徴

1. **画像比率に自動最適化（余白ゼロ化）**
   - アップロードされた画像の縦横比（はがき・A判比率 `1:1.414`、スマホ比率 `9:16`、チラシ比率など）に合わせて、A4横用紙（297×210mm）に収まる最大カード寸法を自動計算。
   - **上段（#1〜#4）の底辺と下段（#5, #6）の天辺が1本のカットライン上に隙間なく密着**するため、2重カットの手間が不要です。

2. **直線カット8本だけで全6枚が完成（時短カッティング）**
   - 下段の2枚を上段2列分（135mm）にスナップ。
   - **用紙の端から端まで通る「縦5本・横3本」の直線カットだけ**で、下段の個別4辺カットをすることなく手早く全6枚が切り離せます。

3. **完全ブラウザ完結（JavaScript / TypeScript + pdf-lib）**
   - 画像データが外部サーバーへ送信されないため、セキュリティ・プライバシー面でも安心。
   - サーバー不要で動作が極めて高速。

4. **両面印刷対応**
   - 裏面用画像をアップロードすると、裏返した際に位置がピッタリ一致するように左右反転した2ページ目PDFを自動生成。

## 🚀 ローカル開発環境の起動

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (デフォルトポート 5190)
npm run dev
```

ブラウザで `http://localhost:5190/` を開いてご利用ください。

## ☁️ Cloudflare Pages へのデプロイ手順

本アプリケーションは完全な静的サイト（SPA）のため、Cloudflare Pages に $0 で簡単にデプロイ・公開できます。

以下の **2つの方法（CLI直接デプロイ / GitHub連携）** のいずれかを選択してください。

### 方法 1: ターミナル (Wrangler CLI) から直接デプロイ 【おすすめ・最短】

1. **Cloudflare にログイン（初回のみ）**:
   ```bash
   npx wrangler login
   ```
   ※ブラウザが立ち上がるので、Cloudflareアカウントで承認してください。

2. **デプロイを実行**:
   ```bash
   npm run deploy
   ```
   自動的にビルド（`dist` 出力）が実行され、Cloudflare Pages 上にプロジェクトが作成・公開されます。完了すると公開用 URL（`https://flyr.pages.dev` など）が表示されます。

---

### 方法 2: GitHub 連携による自動デプロイ (CI/CD)

1. このプロジェクトを GitHub / GitLab リポジトリにプッシュします。
2. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) にログインします。
3. **「Workers & Pages」 > 「作成」 > 「Pages」 > 「Git に接続」** を選択します。
4. 対象のリポジトリを選択し、以下のビルド設定を入力します：
   - **プロジェクト名**: `flyr`（または任意）
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. **「保存してデプロイ」** をクリックします。
   ※以降は `git push` するたびに自動でデプロイが実行されます。

## ✂️ 裁断（カッティング）手順

定規とカッターナイフを使って、最も手早く綺麗に6枚を切り分ける手順です：

1. **外周の余白カット**: 上辺・下辺・左辺・右辺の4本の一番外側の直線に沿って、一直線に切り落とします。
2. **中央水平ラインのカット**: 上段（4枚の縦フライヤー）と下段（2枚の横フライヤー）の境目の水平線を切断します。
3. **上段の縦ラインカット**: 上パーツの3本の縦線に沿って切断すると、縦向きフライヤー4枚が完成します。
4. **下段の中央ラインカット**: 下パーツの中央（境界線）を切断すると、横向きフライヤー2枚が完成します。（合計6枚）

## 🖨️ 印刷時の推奨設定

自宅やコンビニ等のプリンターで印刷する際は、以下の設定を推奨します：
- **倍率**: `100%`（「実際のサイズ」/「拡大縮小なし」）※「用紙に合わせる」にすると数mm縮小される場合があります
- **用紙方向**: `横向き (Landscape)`
- **用紙サイズ**: `A4`
